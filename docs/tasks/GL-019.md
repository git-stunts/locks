## 1. Background Context

Historical evidence uses inconsistent manifests and source pins. A changed checkout can make a valid historical report look current.

## 2. Problem Description

Historical evidence uses inconsistent manifests and source pins. A changed checkout can make a valid historical report look current.

## 2b. Proposed Solution

Verify artifact bytes, source identity, and measurement context for every retained evidence family.

## 2c. Alternatives considered and rejected

Do not remove source pins merely to make a verifier pass.

## 2d. Acceptance Criteria

- [ ] Inventory demonstration, observation, and benchmark evidence.
- [ ] Preserve historical claims at their original revisions.
- [ ] Detect changed bytes, missing files, stale current claims, and merge/index cases.
- [ ] Separate integrity, coverage, and workflow approval in results.

## 2e. Test Plan

Golden: Verify an intact historical bundle.
Edges: Check staged files, merge states, and alternate revisions.
Known failure modes: Corrupt a copy and require a precise failing diagnostic.
Fuzz and stress: Bound fixture copies and retained logs.
