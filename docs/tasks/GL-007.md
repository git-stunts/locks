## 1. Background Context

Some schema events and prose have no demonstrated emitter. Stream and exit semantics need one checked contract.

## 2b. Proposed Solution

Implement the selected acquisition contract and generate or verify event, stream, exit, and command reference tables.

## 2c. Alternatives considered and rejected

Keep historical schema versions identifiable; do not silently tighten old records.

## 2d. Acceptance Criteria

- [ ] Trace every public event to its producer and consumer documentation.
- [ ] Remove or implement unused schema events with an explicit compatibility decision.
- [ ] Define stream and exit metadata without confusing wrapped child output with CLI output.
- [ ] Keep generated help from PR #119 and check documentation drift.

## 2e. Test Plan

Golden: Validate every exercised event against the schema.
Edges: Cover help, refusal, cancellation, and wrapper exit 125.
Known failure modes: Negative fixtures detect an extra event or wrong stream.
