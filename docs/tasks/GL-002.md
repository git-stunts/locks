## 1. Background Context

The README names Git 2.31. Current source and recent tests do not establish that minimum on every supported platform.

## 2. The Question

What minimum Git version supports the current reservation protocol on the declared platforms?

## 2b. What decision waits on it

Record the oldest tested Git version that supports the advertised commands and state protocol.

## 2c. What would settle it

- [ ] Run actual candidate Git binaries with the full CLI and object-format cases.
- [ ] Record source hashes, build inputs, platforms, and unsupported combinations.
- [ ] Update support claims and CI only to match demonstrated results.

Golden: Minimum candidate runs the full suite.
Edges: Exercise SHA-1 and supported SHA-256 stores.
Known failure modes: Reject unsupported features with useful diagnostics.
Fuzz and stress: Build one candidate at a time inside the existing budget.

## 2d. Aperture

One platform or object format cannot prove support for another.

## 2e. Possible answers and what each implies

Keep 2.31 if the complete matrix passes; otherwise raise the documented floor or add a bounded compatibility fix.
