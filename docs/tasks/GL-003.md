## 1. Background Context

## 2. Problem Description

## 2b. Proposed Solution

Integrate one guarded preparation path with real privileged Linux evidence and working fresh CI.

## 2c. Alternatives considered and rejected

Keep unsupported bootstrap fail-closed; do not merge a branch that breaks all fresh CI.

## 2d. Acceptance Criteria

- [ ] Reuse a matching image; refuse unsupported setup before unaccounted work.
- [ ] Cover image acquisition, build, export, load, writable layers, caches, temporary data, and logs.
- [ ] Enforce 20 GiB build, 4 GiB runtime, and 128 MiB logs; preserve the 50 GiB free-space floor.
- [ ] Prove timeout, cancellation, monitor failure, and teardown stop all owned child work.
- [ ] Pass both cached-image and missing-image CI without host mounts in the ordinary test worker.

## 2e. Test Plan

Golden: Reuse and fresh setup both pass.
Edges: Exercise recipe changes, low space, and filled quotas.
Known failure modes: Kill the monitor and interrupt each setup phase.
Fuzz and stress: Use bounded pilots on the actual privileged kernel path.
