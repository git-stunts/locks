## 2. Problem Description

Developers need a clear report of tool presence and supported versions.

## 2c. Alternatives considered and rejected

## 2d. Acceptance Criteria

- [ ] Report actual selected executable paths and versions.
- [ ] Separate runtime requirements from optional development tools.
- [ ] Refuse unsupported required tools with actionable messages; do not install them silently.

## 2e. Test Plan

Edges: Cover missing Docker, Python modules, PATH entries, and old Bash or Git.
Known failure modes: Do not initialize a store or change configuration.
