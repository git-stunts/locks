## 1. Background Context

Planner functions mix decisions, diagnostics, and process exits. Callers use subshells to contain those exits.

## 2. Problem Description

Planner functions mix decisions, diagnostics, and process exits. Callers use subshells to contain those exits.

## 2b. Proposed Solution

Make planners return typed results and let command boundaries render diagnostics and exit.

## 2c. Alternatives considered and rejected

Do not replace the CLI oracle with a test double.

## 2d. Acceptance Criteria

- [ ] Preserve each refusal reason, stream, exit code, and atomicity rule.
- [ ] Remove planner-owned process exits from the chosen public planner paths.
- [ ] Keep snapshot refresh and parent-shell state correct after retries.

## 2e. Test Plan

Golden: Compare planner results with current CLI behavior.
Edges: Cover stale roots, invalid records, and batch failures.
Known failure modes: Cancellation must not leave admission or child processes behind.
Fuzz and stress: Run the full safety suite and calibrated observation cases.
