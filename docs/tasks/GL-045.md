## 1. Background Context

Process groups, admission, lease renewal, deadlines, and cleanup require a coherent supervisor. The Rust preview must preserve default wrapper behavior and implement the selected opt-in lifecycle contract.

## 2. Problem Description

Process groups, admission, lease renewal, deadlines, and cleanup require a coherent supervisor. The Rust preview must preserve default wrapper behavior and implement the selected opt-in lifecycle contract.

## 2b. Proposed Solution

Run child commands under a bounded Rust supervisor with identity-guarded renewal/loss response and complete cleanup.

## 2c. Alternatives considered and rejected

A partial result that depends on a later repair is not independently mergeable. Retaining the working reference remains the fallback until the scoped candidate passes.

## 2d. Acceptance Criteria

- [ ] Acquire requested paths and optional slot together, reverify before launch, and prevent launch on uncertain or lost admission.
- [ ] Preserve terminal/stdin ownership, signals, command status, background-child cleanup, and explicit detached-session exclusions.
- [ ] Implement the selected opt-in atomic path/slot renewal and stop-and-report response to failure or supersession.
- [ ] Use monotonic elapsed admission/I/O/supervision deadlines while preserving the selected wall-clock lease interoperability rules.
- [ ] Resolve renewal/cancellation/cleanup races by acquisition identity; no heartbeat or owned child may outlive the wrapper.
- [ ] Keep ordinary default commands compatible and state clearly that this supervisor is not a resource fence.

## 2e. Test Plan

- Golden: child status and streams preserved.
- Edges: PTY/non-PTY, Ctrl-Z/resume, command exit during renewal, signals during CAS, renewal shortening, and expired/superseded acquisitions.
- Failures: stuck plumbing, stopped owner, failed renewal, TERM-resistant child, and cleanup failure produce bounded evidence and no successful lifecycle receipt.
