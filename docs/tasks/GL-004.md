## 1. Background Context

The old audit describes per-ref name failures. The current authority stores names in immutable tree entries.

## 2. The Question

Which reported name failures still occur with the immutable-root protocol?

## 2b. What decision waits on it

Reproduce each name case on the current protocol and record the supported identity contract.

## 2c. What would settle it

- [ ] Test a..b, a.lock, a., names longer than 255 bytes, and mixed-case pairs.
- [ ] Cover claims, release, renewal, families, and semaphore lifecycle.
- [ ] Check both Git case settings and the declared filesystem support boundary.
- [ ] Close obsolete findings with evidence; create a scoped defect task for any current failure.

Golden: Each valid name round-trips without identity loss.
Edges: Case variants remain distinct when the contract promises it.
Known failure modes: Operational failures do not masquerade as an existing semaphore.
