## 1. Background Context

Many argument errors still print the full usage object. The HOME and clock defects have separate landed fixes.

## 2. Problem Description

Many argument errors still print the full usage object. The HOME and clock defects have separate landed fixes.

## 2b. Proposed Solution

Give malformed command arguments a concise structured diagnostic while preserving documented exit and help behavior.

## 2c. Alternatives considered and rejected

Do not replace every refusal with usage; preserve conflict and operational error classes.

## 2d. Acceptance Criteria

- [ ] Enumerate argument-error paths across all commands.
- [ ] Report the offending option or missing value without a raw shell error.
- [ ] Preserve explicit help, wrapped command streams, and the documented error schema.

## 2e. Test Plan

Golden: Valid calls and help preserve behavior.
Edges: Test missing values, unknown options, empty inputs, and missing separators.
Known failure modes: Invalid input performs no store mutation or child launch.
Fuzz and stress: Use a bounded argument matrix and retain each failing parent case.
