## 2. Problem Description

## 2b. Proposed Solution

Produce reproducible artifact manifests and verification for the migration release candidates.

## 2c. Alternatives considered and rejected

A partial result that depends on a later repair is not independently mergeable. Retaining the working reference remains the fallback until the scoped candidate passes.

## 2d. Acceptance Criteria

- [ ] Bind binary/script, schema, source revision, selected toolchain, dependencies, and build recipe.
- [ ] Verify checksums and the selected signing identity from a clean consumer fixture.
- [ ] Detect artifact substitution and wrong signing identity.
- [ ] Define platform packaging and the retained Bash fallback without shipping an unverified Rust command set.
- [ ] Prepare artifacts locally or in authorized test release infrastructure; public release remains separately authorized.

## 2e. Test Plan

- Golden: exact artifacts verify.
